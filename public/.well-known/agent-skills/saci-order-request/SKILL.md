# Cerere de ofertă pentru saci.md

## 1. Adună datele lipsă

Cere doar informațiile care nu are deja:

- Tipul sacului (polipropilenă, polietilenă, plasă, big bags, stretch).
- Dimensiunile sau capacitatea necesară.
- Cantitatea (bucăți sau paleți).
- Produsul împachetat (cereale, făină, zahăr, deșeuri, nisip, fructe).
- Locul de livrare (oraș, regiune).
- Termenul dorit.
